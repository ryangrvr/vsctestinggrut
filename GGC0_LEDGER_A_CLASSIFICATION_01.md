## A-1 Static substrate (site/net structure, K-type coupling, C1-a class)

- **Recorded status:** "two separate primitive-looking layers: the static substrate (K, net); the temporal generator class. Neither is derived from the other on the present record." (`S5_OWNER_RULING_01.md:88-92`); class scope `L0_1A_OWNER_RULING_01.md:23-25`.
- **Q1:** The recorded C1-a class admits many substrates (chains, rings, expanders, half-plane — P-01 parents). Varying the substrate within the class leaves an admissible instance of the same governing construction; the derived edges (gap→memory etc.) are class-level facts over that variation. → **SOLUTION-LIKE**.
- **Q2:** One unchanged specification (the C1-a construction class) admits many instances differing in the particular net. The particular net is selected when a particular solution/model is chosen. → **SOLUTION-LIKE**.
- **Q3:** Comparator: effective field theory — the UV regulator/lattice choice is model detail, not law. Scope matched (microscopic construction within a declared class). → supports SOLUTION.
- **Verdict: SOLUTION-LIKE.**
- **Adversarial counterargument:** the substrate determines *which* effective structures exist at all (geometry, locality); calling it "model detail" presumes the class hierarchy is itself not law-like — the very question under test.

## A-3 Temporal generator (Level-0 first-order dissipative G-D)

- **Recorded status:** "S5-0 = GENERATOR-IRREDUCIBLE/SUPPLIED"; "Nothing GRUT has already earned selects the kind of temporal generator." (`S5_OWNER_RULING_01.md:9,11-13`).
- **Q1:** Varying the generator changes the dynamical map — the governing rule itself — not merely which state or history occurs. Within the recorded class the variation may be *admissible*, but it changes the rule that determines permissible solutions. → **LAW-LIKE**.
- **Q2:** The criterion's rule-determining list explicitly includes the dynamical map; the generator is the dynamical map. One unchanged specification cannot admit two instances with different generators, because the generator is part of the specification. → **LAW-LIKE**.
- **Q3:** Comparator: force law / Hamiltonian in mechanics — the generator of dynamics is the theory's content; the state is solution. Scope matched. → supports LAW.
- **Verdict: LAW-LIKE.**
- **Adversarial counterargument:** at effective-model scope, choosing a generator is choosing a *model* within a fixed framework (like choosing a Hamiltonian within QM), which standard practice treats as model selection, not law selection; the framework/generator distinction is exactly what G2 must confront.
