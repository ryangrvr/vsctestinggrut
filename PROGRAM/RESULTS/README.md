# RESULTS

One folder per work order (`WO-NNN/`): committed code, machine-readable output,
generated tables, and a short `REPORT.md`. Claude Code's definitions, proofs, and
audits live in topic folders (e.g. `R1/`).

Nothing here goes on `SCOREBOARD.md` until it has been reviewed (see
`DIVISION_OF_LABOR.md`). Every proof, theorem statement, or comparator verdict written
outside review carries the mark `DRAFT — pending Claude Code review`.
