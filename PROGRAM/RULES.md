# RULES — the entire governance (one page)

**Session protocol.**
- Start: read `PROGRAM/NORTH_STAR.md`, then `PROGRAM/DIVISION_OF_LABOR.md`, then
  `PROGRAM/STATE.md`, then `PROGRAM/SCOREBOARD.md`, then any `OPEN` order in
  `PROGRAM/WORK_ORDERS/`, before doing anything else.
- End: update `STATE.md` (where we are, what changed, what's next, what's blocked),
  commit, push, and verify the push from the remote.
- Work at forest level: every step moves one of the six stages. Target about 80%
  physics and mathematics, about 20% governance. No charter per step; no ruling per
  commit.

1. **Commitment ≠ relocation.** Postulates are allowed if they are priced. RELOCATED
   means the answer is encoded in the input.
2. **Compression scoreboard.** Prices are measured in the fixed base language L₀,
   declared before any candidate: finite sets, maps, interventions, conditional
   response, composition, logic. Target-encoding vocabulary carries a price: Hilbert
   space, orthogonality, quantum set, GPT cone, Born rule, metric.
3. **CROSS-SECTOR** means a forced quantitative relation between otherwise independent
   sectors. Analogy and shared vocabulary don't count.
4. **Short ladders.** conjecture → derivation → hostile control → holdout → extension,
   then KILL / BANK / EXTEND. There are no prerequisite staircases: a failure is
   recorded in `GRAVEYARD.md` and the stage stops. It does not spawn a
   "missing ingredient" campaign.
5. **Honesty.**
   - Never claim a theorem you haven't proved.
   - NOT FOUND ≠ IMPOSSIBLE.
   - Verify literature against primary sources.
   - Verify every push from the remote.
6. **Numerics.**
   - Pipeline: computed → machine-readable output → generated tables. No
     hand-transcribed numbers.
   - Include at least one exact identity or conserved quantity as a control.
7. **No novelty claims without the comparator audit.**

**Checkpoints.** Stop and report to the owner after:
- (a) the continuity files exist;
- (b) the SD0 outcome;
- (c) the R1 result;
- (d) the three 𝒦 cards;
- (e) each stage-4 and stage-5 gate result.

Each report is five lines or fewer: stage · result · scoreboard change · next action ·
blockers.

**Status vocabulary (scoreboard):** DERIVED / COMMITMENT / COMPRESSIVE / PREDICTIVE /
CROSS-SECTOR / RELOCATED / RESTATED.
