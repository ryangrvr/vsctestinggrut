## S6.1 Second numerical code path {#sec:S6-second}

As a manuscript-stage cross-check of the frozen result, the finite-$N_B$ values of Section 6 were recomputed by a separately written implementation that shares only the model definition with the original computation. It uses Gauss–Legendre quadrature in position combined with Gauss–Hermite quadrature in momentum, and an adaptive eighth-order Dormand–Prince integrator, in place of a tensor Gauss–Legendre grid with a fixed-step fourth-order Runge–Kutta integrator. This cross-check is a reproducibility artifact. It is not an additional verification of the theorem, not an external replication, and it does not change the evidence grade of the illustration.

The two computations agree in $\gamma_1$ to within ${{second.max_rel_diff_tstar}}$ in relative terms at $t_\star = 0.5$ and ${{second.max_rel_diff_t1}}$ at $t = {{num.t_diag_3}}$, with the same sign, at every bath size (Table S6.1); the reference-protocol variances agree to ${{second.ref_var_reldiff}}$. Like the original, the second implementation resolves the finite-$N_B$ correction at $t = {{num.t_diag_3}}$ (a drift of $N_B\gamma_1$ of ${{second.drift_t1}}$ between the smallest and largest bath sizes) and none at $t_\star$.

## S6.2 Reproducibility {#sec:S6-repro}

The authoritative numerical output was regenerated by re-running, unchanged and in a separate directory, the script that produced it. All ${{repro.n_values}}$ numerical entries were recovered with identical structure: the ${{repro.n_sig}}$ entries above round-off level agree to ${{repro.max_rel}}$ in relative terms, and the remaining entries, which are at round-off level, to ${{repro.max_abs_roundoff}}$ in absolute terms. The agreement is not bitwise, as expected across numerical-library versions.
